# Создание проекта

Проект — контейнер для задач, досок и участников. Создаётся кнопкой «Новый
проект» или методом `POST /api/v1/projects`.

## Обязательные поля

Для создания нужны `name` (название) и `key` (короткий буквенный код, 2–5 букв,
используется в номерах задач вида ORB-42). Ключ нельзя изменить после создания.

## Шаблоны

Проект можно создать из шаблона: Kanban, Scrum или пустой. Шаблон задаёт
начальный набор колонок доски и статусов задач.
