# Задачи

Задача — единица работы внутри проекта. У задачи есть статус, исполнитель,
приоритет и срок.

## Статусы

Базовые статусы: «К выполнению», «В работе», «На проверке», «Готово». Набор
статусов настраивается на уровне проекта администратором.

## Приоритеты и сроки

Приоритет — один из: низкий, средний, высокий, критический. Срок (due date)
задаётся датой; за сутки до срока исполнителю приходит напоминание.
