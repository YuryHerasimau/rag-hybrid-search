# Вебхуки

Вебхук отправляет HTTP POST на ваш URL при событиях в проекте — например,
создании задачи или смене статуса.

## Настройка

Вебхук создаётся методом `POST /api/v1/webhooks` с полями `url` и списком
`events` (например `task.created`, `task.status_changed`). Орбита шлёт JSON с
телом события.

## Подпись запроса

Каждый запрос подписывается: заголовок `X-Orbita-Signature` содержит HMAC-SHA256
тела по вашему секрету. Проверяйте подпись, чтобы отсеять поддельные вызовы.
