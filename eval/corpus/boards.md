# Доски

Доска визуализирует задачи проекта по колонкам-статусам. У проекта может быть
несколько досок — например, отдельная для бэклога и для спринта.

## Канбан и спринты

На канбан-доске задачи движутся по колонкам без ограничения по времени. На
scrum-доске работа ведётся спринтами фиксированной длины (1–4 недели).

## WIP-лимит

Для колонки можно задать WIP-лимит — максимум задач «в работе» одновременно.
При превышении колонка подсвечивается, сигналя о перегрузке.
