# API-ключи

API-ключ — долгоживущий токен для серверных интеграций, которым не нужен вход по
email. В отличие от access-токена, не истекает по времени.

## Создание и отзыв

Ключ создаётся в разделе «Настройки → API-ключи». Полное значение показывается
один раз при создании — сохраните его. Ключ можно отозвать в любой момент; после
отзыва запросы с ним получают 401.

## Права ключа

Ключу назначается область (scope): только чтение или чтение и запись. Рекомендуем
выдавать минимально необходимую область.
